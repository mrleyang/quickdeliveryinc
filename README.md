# QuickDeveleryInc

Application web de type service de livraison inspirée de FedEx.

## Fonctionnalités

- Inscription utilisateur
- Connexion utilisateur et administrateur
- Dashboard client avec création d’expéditions
- Dashboard admin avec gestion des statuts
- Suivi de colis par numéro de suivi
- Base SQLite locale

## Comptes de démonstration

- Client : client@fedexclone.test / client123
- Admin : admin@fedexclone.test / admin123

## Démarrage

```bash
npm install
npm start
```

Puis ouvrez http://localhost:3000
